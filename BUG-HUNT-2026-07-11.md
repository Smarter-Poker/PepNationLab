# PepNationLab Global Bug Hunt — Swarm Audit Report

**Date:** 2026-07-11
**Scope:** PepNationLab app only (`app/`, `components/`, `lib/`, `middleware.ts`, `next.config.ts`, `supabase/migrations/`). Excludes `pepnationrx/` and repo-root scripts (root debris noted where security-relevant).
**Mode:** Read-only audit. No code changed, nothing committed or deployed.
**Swarm:** 7 specialist agents (ALPHA logic, BETA frontend, GAMMA API, DELTA data, EPSILON wiring, ZETA debt, THETA regression) + OMEGA coordinator.

> Findings cite exact `file:line`. Severities are OMEGA's after cross-referencing and deduping. Two of the top items were independently re-verified by the coordinator (see "Verified" tags).

## Executive Summary

The application layer is, on the whole, heavily hardened from prior audits: API auth-guard coverage is complete, IDOR scoping is consistent, the order route computes prices server-side with idempotency and full rollback, SECURITY DEFINER functions have pinned `search_path`, and the app/components/lib tree is nearly free of classic debt (one TODO, zero emojis in source, one commented block).

The danger is concentrated in five places:

1. **A leaked production `service_role` key** committed in 9 tracked scripts of a repo documented as public. **Verified.**
2. **A just-shipped middleware rename** that silently 401s **12 scheduled cron jobs** — including weekly sub-agent billing settlement, stale-order cancellation, and coupon expiry. **Verified.**
3. **The per-10-vial pricing convention leaking un-divided into checkout** (super-agent baseline billed at 10x) plus a **client-controlled `bundleName`** that hands any researcher a 10% discount.
4. **Three first-generation RLS policies** that still allow direct PostgREST writes bypassing every business rule (self privilege-escalation, arbitrary order insert, unguarded order update).
5. **A Rules-of-Hooks violation in checkout** that should crash the entire checkout flow into its error boundary.

## Top 10 Most Dangerous Issues

1. **Production `service_role` key hardcoded in 9 git-tracked scripts** — full RLS bypass. `get_products.js:3`, `scripts/populate-embeddings.mjs:11`, +7 more. **[Verified: decoded JWT shows `"role":"service_role"`, `ref: ydsaqnnuwyvtyxgvrnys`.]**
2. **12 scheduled crons now 401 in production** — middleware auth allowlist is per-path and misses `cancel-stale-pending`, `coupons-expire`, `sub-agent-settle`, `tier-recompute`, `refill-reminders`, `balance-alerts`, `inventory-alerts`, `integrity-audit`, `coa-audit`, `generate-embeddings`, `idempotency-sweep`, `social-content-gen`. `middleware.ts` PUBLIC_ROUTES vs `vercel.json`. **[Verified by diff.]**
3. **Super-agent baseline billed at 10x** — per-10-vial cost assigned as per-vial unit cost at `app/api/orders/route.ts:463-465`; same bug in invoice cron `app/api/cron/invoices/route.ts:149-155`.
4. **Self privilege-escalation via unprotected profile columns** — `account_type`, `max_auto_approve_limit`, `credit_used`, `locked_tier_level` etc. are user-writable through PostgREST; combined with the auto-approve check at `orders/route.ts:888`, a researcher can grant themselves approved-shipped orders with no payment. `migrations/20260605030000...v2.sql:9-21`.
5. **Arbitrary order insert via RLS** — "Buyers can create orders" policy lets any authenticated user insert an `approved_ship`, $0-total order directly. `migrations/20260521000001_initial_schema.sql:445-446`.
6. **Client-controlled bundle discount** — unvalidated `bundleName` applies a flat 10% cut to any line item. `app/api/orders/route.ts:509-512`.
7. **Rules-of-Hooks violation crashes checkout** — early `return null` at `CheckoutForm.tsx:653` sits above a `useEffect` at `:749`; hook count changes between renders. `app/checkout/CheckoutForm.tsx`.
8. **DST week permanently skipped in billing** — spring-forward causes the Feb 23–Mar 1 statement week to never be billed. `lib/time-cst.ts:45-69` + `vercel.json:15`.
9. **Tier multipliers leaked to researchers** — checkout server component reads `pricing_tiers` with the service client and serializes multipliers to every researcher, undoing the RLS lockdown. `app/checkout/page.tsx:40-48,108-118`; anon product reads also expose `base_cost` (`migrations/20260707010000_guest_products_visibility.sql:6-7`).
10. **Unguarded order UPDATE via RLS** — agents can directly zero `total`/`shipping_cost`/`subtotal` on their own orders before the billing cron reads them. `migrations/20260521000001_initial_schema.sql:448-449`.
